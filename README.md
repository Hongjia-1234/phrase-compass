# Phrase Compass 2.2 — 英语短语新闻证据台

Phrase Compass 是一个在自己电脑上运行的英语短语查询工具。输入一个连续、精确的 2–8 词英语短语后，它会查询最近的英语新闻，分别显示美国新闻来源和英国新闻来源中有多少篇文章匹配，并给出可供核对的新闻示例。

这个版本提供的是“新闻用例证据”，不是英语考试判分器：它可以帮助你判断最近新闻中是否有人这样写，但不能仅凭匹配数量证明一句话一定正确或错误。

![Phrase Compass 桌面端界面](docs/phrase-compass-desktop.png)

## 2.2 界面改版

- 使用“现代新闻编辑台”视觉系统，让查询、结论和证据之间的层级更清楚；
- 中文界面使用本地打包的 Noto Sans SC Variable，英文短语使用 Newsreader Variable，不依赖境外字体 CDN；
- 顶部导航可直接跳转到查询、结果、方法和数据来源；
- API Key 设置默认折叠，额度用量和 80 次保护上限集中显示；
- 结果页支持键盘方向键切换标签，并为读屏软件提供规范的 tab 语义；
- 桌面、平板和手机端均保留完整的常见度、置信度、重新查询和导出功能；
- 支持减少动态效果的系统设置，并补充清晰的键盘焦点样式。

## 运行前需要准备

你需要：

- Windows 电脑；
- Node.js 20 或更高版本；
- 可以访问 npm 和 GNews API 的网络；
- 你自己的 GNews API key。

如果还没有 Node.js，请从 [Node.js 官方网站](https://nodejs.org/)下载安装长期支持版。安装完成后，关闭已经打开的命令行窗口，再重新打开。

GNews API key 可以在 [GNews](https://gnews.io/) 注册账号后，从账户面板中取得。API key 相当于你账户的密码：不要发给别人，不要贴到聊天、论坛或截图中，也不要使用别人共享的 key。

## 最简单的启动方法（推荐）

1. 把下载的压缩包解压到一个新文件夹。
2. 打开解压后的文件夹，直接双击：

   ```text
   start-phrase-compass.bat
   ```

3. 第一次运行时，它会自动执行依赖安装，请保持网络连接并耐心等待。
4. 安装完成后，程序会自动启动，并打开 `http://localhost:3000`。
5. 使用期间请保持黑色窗口打开。要停止程序，请回到这个窗口，按 `Ctrl + C`。

如果双击后提示没有检测到 Node.js，请先安装 Node.js 20 或更高版本。安装完成后重新双击这个文件。如果自动启动失败，请使用下面的备用方法查看详细错误。

## 备用启动方法：用 cmd 逐条运行

1. 打开解压后的文件夹，确认里面能看到 `package.json`。
2. 单击文件资源管理器顶部的地址栏，让当前文件夹路径被选中。
3. 在地址栏输入：

   ```text
   cmd
   ```

4. 按回车。系统会在当前文件夹打开黑色命令行窗口。
5. 在黑色窗口中输入下面第一条命令并按回车：

   ```cmd
   npm install
   ```

6. 等待安装完成，重新出现当前文件夹路径和闪烁光标后，再输入第二条命令：

   ```cmd
   npm run dev
   ```

7. 保持黑色窗口打开，在浏览器访问：

   [http://localhost:3000](http://localhost:3000)

不要把两条 npm 命令粘在同一行。第一次执行 `npm install` 可能需要几分钟；以后通常只需运行 `npm run dev`。

要停止程序，请回到黑色窗口，按 `Ctrl + C`。关闭这个窗口也会停止本地网站。

## 页面使用方法

1. 在页面的 GNews API key 输入框中粘贴你自己的 key，然后单击“保存”。
2. 默认情况下，key 会在关闭浏览器后清除；如要长期保留，请勾选“记住在这台电脑”后再次保存。页面也提供清除密钥按钮。
3. 输入一个连续的 2–8 词英语短语。
4. 单击分析按钮一次，然后等待结果。不要连续点击。
5. 查看美国新闻来源、英国新闻来源、匹配文章数和新闻示例。

API key 只应输入到你自己电脑上的 `localhost:3000` 页面。分享故障截图前，请先确认截图中没有 key。

## 一次分析会使用多少额度

每个未缓存的新短语通常会进行两次 GNews 查询：

1. 查询美国新闻来源；
2. 约 1.2 秒后查询英国新闻来源。

成功结果会缓存 24 小时。再次查询同一个短语时，程序会尽量使用缓存，因此通常不会马上再次消耗两次额度。缓存可能在浏览器数据被清理、程序重启或版本更新后失效，以页面显示为准。

GNews 免费账户通常有每日 100 次请求额度。按每个新短语两次请求估算，理论上最多约 50 个尚未缓存的短语。为了给失败请求、手动刷新和其他意外情况留余量，本程序会在本机估算达到 80 次时暂停新的联网查询，相当于每天约 40 个新短语；已缓存结果仍可查看。

页面显示的“今日已用”只统计这个浏览器通过 Phrase Compass 发起并收到响应的请求，是保护性估算：更换浏览器、清除浏览器数据、同时打开多个页面，或在别处使用同一 API key 都可能使它与账户实际数字不同。**GNews 账户 Dashboard 的用量始终是最终准数。**“重新联网查询”会跳过缓存，通常再消耗两次，请只在确实需要时使用。

## 怎样正确理解结果

请特别注意以下限制：

- “美国”和“英国”表示新闻发布来源所在国家，只是美式与英式用法的近似代理，不代表文章作者的国籍，也不等于完整的美式或英式英语语料库。
- `totalArticles` 表示匹配该短语的文章数，不是短语出现的总次数，也不是每百万词频率。一篇文章即使重复使用多次，仍可能只计为一篇。
- 不同新闻来源可能转载相同内容，且美国、英国的新闻收录规模不一定相同，因此两边数字不能当作精确的方言比例。
- 免费数据通常约有 12 小时延迟，不适合追踪刚刚发生的新闻。
- 新闻语言偏正式，不能代表日常口语、小说、邮件或社交媒体中的全部英语用法。
- 结果为 0 只表示当前新闻样本中没有检出，绝不等于短语错误。

因此，页面结果应读成“近期新闻中观察到多少篇匹配文章”，而不是“这个短语绝对正确或错误”。样本很少时，应保留判断。

## 常见故障排查

### HTTP 401：API key 无效

- 回到 GNews 账户面板，重新复制 key；
- 确认 key 前后没有空格；
- 确认没有粘贴账号密码、邮箱或其他文字；
- 如 key 已被撤销，请在 GNews 账户中生成或复制当前有效的 key。

### HTTP 403：额度已用完或账户计划不可用

- 查看 GNews 账户中的当日用量和计划状态；
- 免费额度用完后，需要等待账户额度重置；
- 额度重置时间和规则可能变化，请以 GNews 账户页面当前显示为准；
- 已缓存的旧结果仍可能可用，新短语在额度恢复前无法查询。

### HTTP 429：请求过快

- 不要连续点击分析按钮；
- 关闭重复打开的 Phrase Compass 页面或重复运行的本地服务；
- 等待一会儿再重试；
- 程序会把两次查询间隔约 1.2 秒，但账户侧仍可能因短时间请求过多而限速。

### 显示网络故障、超时或无法连接

- 确认电脑可以正常访问 [GNews](https://gnews.io/)；
- 检查 VPN、代理、防火墙和安全软件是否阻止 Node.js 联网；
- 保持 `npm run dev` 的黑色窗口打开，并查看其中是否有错误信息；
- 稍后再试。服务器临时维护或网络波动也可能造成失败；
- 网络失败不是“短语错误”，程序不应把失败当作 0 条结果。

### `npm` 不是内部或外部命令

Node.js 尚未正确安装，或安装后旧命令行窗口没有重新打开。安装 Node.js 20 或更高版本，然后关闭并重新打开 `cmd`。

### 浏览器打不开 `localhost:3000`

- 确认 `npm run dev` 仍在运行；
- 确认地址是 `http://localhost:3000`；
- 查看黑色窗口是否提示端口被占用或启动失败；
- 如已停止程序，请重新运行 `npm run dev`。

## 测试与构建

普通使用者不需要运行下面的命令。修改代码后，可以在项目文件夹的命令行中逐条运行：

```cmd
npm test
npm run build
```

`npm test` 用于检查查询与限速相关逻辑，`npm run build` 用于确认项目可以完成正式构建。命令全部成功后，才能说明当前代码通过了这些自动检查；它们不会保证外部网络和 GNews 服务永远可用。
